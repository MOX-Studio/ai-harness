# AI Harness

Общие skills, MCP, плагины и инструкции для Codex.

- **При запросе синхронизации harness:** выполни [update_harness](skills/update_harness/SKILL.md).
- **Состав набора:** читай [catalog.json](catalog.json). Пути — от корня репозитория.
- **Инструкции пользователя:** [AGENTS.md](AGENTS.md).
- **Изменение набора:** редактируй запрошенный артефакт, обнови каталог и версию.

Навыки — `skills/`, MCP — `mcp/`, плагины — `plugins/`. Устанавливай только записи каталога. Сохраняй личные дополнения пользователя.
