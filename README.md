# MOX · AI Harness

Общие **skills, MCP, плагины и пользовательские инструкции** для AI-агентов команды.

| Что храним | Где |
| --- | --- |
| Пользовательские инструкции | [AGENTS.md](AGENTS.md) |
| Навыки | [skills/](skills/) |
| MCP | [mcp/](mcp/) |
| Плагины | [plugins/](plugins/) |

[catalog.json](catalog.json) перечисляет артефакты для подключения. Сейчас в нём `AGENTS.md`, навык `update_harness` и Notion MCP; список плагинов пока пуст.

## Подключить или обновить

Передайте агенту:

```text
Подключи общие артефакты MOX, сохранив мои личные дополнения.
Прочитай и выполни навык:
https://github.com/MOX-Studio/ai-harness/blob/main/skills/update_harness/SKILL.md
```

После установки: **`/update_harness` в Claude Code** или **`$update_harness` в Codex**.

Навык получает обновления репозитория, подключает инструкции и skills, затем обрабатывает MCP и плагины по каталогу. Вход в сервисы каждый сотрудник проходит под своим аккаунтом.

Готовый установщик инструкций и навыков поддерживает Codex и Claude Code на macOS/Linux, требует Git и Python 3.9+. В Codex инструкции добавляются в `~/.codex/AGENTS.md` (или в `CODEX_HOME`), навыки — в `~/.agents/skills/`. В Claude Code используются `~/.claude/CLAUDE.md` и `~/.claude/skills/`. Для остальных сред агент проверяет поддерживаемый способ подключения.

Установщик меняет только блок `ai-harness` и добавляет ссылки на общие навыки. Личный текст и другие навыки сохраняются; конфликт имён требует отдельного решения. Клон нужно хранить на месте. После обновления начните новую сессию агента.

## Добавить артефакт команде

Измените `AGENTS.md` или добавьте файл в соответствующую папку, обновите `catalog.json` и его версию. Навык — папка с `SKILL.md`; для MCP и плагина нужны источник, способ подключения и проверка результата. Личные варианты храните отдельно; в публичный репозиторий добавляйте только предназначенные для общего доступа материалы, без токенов.

Скрипт установки и его проверки находятся внутри `skills/update_harness/`. После изменения установщика запустите:

```sh
python3 -m unittest discover -s skills/update_harness/tests -v
```
