# AI Harness

Общие инструменты и инструкции MOX.

[Skills](skills/) · [MCP](mcp/) · [Плагины](plugins/) · [AGENTS.md](AGENTS.md)

**Подключить:** передайте агенту [update_harness](skills/update_harness/SKILL.md) и попросите настроить harness.

**Обновить:** `/update_harness` в Claude Code, `$update_harness` в Codex.

Автоустановка инструкций и skills: Codex и Claude Code на macOS/Linux, Git и Python 3.9+. MCP и плагины агент подключает средствами клиента; вход — под личным аккаунтом.

**Добавить общее:** положите артефакт в нужную папку, обновите [каталог](catalog.json) и его версию.

Личные дополнения сохраняются. Клон храните на месте; после установки или обновления начните новую сессию.
