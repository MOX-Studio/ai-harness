# MOX · комплект для AI-агента

Общие правила, навыки, подключения и контекст проектов MOX Studio. Новый сотрудник передаёт агенту один навык, а агент подключает доступные артефакты к его рабочей среде. Этим же навыком сотрудник обновляет комплект.

## Начать

Передайте своему агенту:

```text
Подключи мне рабочий комплект MOX для проекта MOX-ADV.
Прочитай и выполни навык:
https://github.com/MOX-Studio/company-ai/blob/main/skills/company-sync/SKILL.md
Сохрани мои личные настройки. Проверь подключение и перечисли, где ещё нужен доступ.
```

После установки достаточно попросить: **«Обнови комплект MOX через company-sync»**.

Готовое подключение общих правил и навыков рассчитано на **Codex и Claude Code на macOS/Linux**. Для других сред агент сначала проверяет поддержку skills, MCP и настроек. Установка в браузерный чат зависит от возможностей рабочего пространства; локальный скрипт сам по себе её не выполняет.

## Общее и личное

Общий комплект хранится здесь. Сотрудник добавляет свои навыки и настройки в личной области агента. Установщик обновляет только блок `company-ai` в файле инструкций и создаёт ссылки на навыки из каталога; другие файлы и текст сохраняются. При конфликте имён он останавливается до записи.

Полезный личный артефакт можно предложить команде через pull request. Папка в публичном репозитории не делает содержимое личным.

Репозиторий публичный. Здесь находятся инструкции и ссылки на рабочие системы; содержимое закрытых страниц, токены, пароли, клиентские данные и локальные истории агентов остаются в своих системах.

## Проверить комплект

```sh
python3 -m unittest discover -s tests -v
```

Установщик проверяет наличие файлов и совпадение общего блока. Доступ к проекту, Notion и фактическую загрузку навыка агент проверяет отдельно в новой сессии.
