# Общие плагины

Дополнительные плагины пока не выбраны; `catalog.json → plugins` пуст. `company-sync` подключается как обычный навык и не требует отдельного плагина.

При добавлении плагина создайте здесь инструкцию и запись в каталоге с полями `id`, `instructions`, `clients`, `projects` и `version`. В инструкции укажите официальный источник/marketplace, штатную команду установки, необходимые права, порядок обновления и проверку результата. Пустой `projects` означает общий плагин для всех проектов; `clients` перечисляет поддерживаемые приложения.

Агент читает инструкции и устанавливает подходящие плагины средствами клиента. Форматы и доступность плагинов могут отличаться между приложениями; совместимость нужно проверить перед включением в общий комплект.
