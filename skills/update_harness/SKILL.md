# /update_harness

Источник: https://github.com/MOX-Studio/ai-harness. Подключай артефакты из `catalog.json` к текущему клиенту, сохраняя личные дополнения сотрудника.

## Получить актуальный набор

Определи клиент из среды. Если установлено несколько, настраивай текущий; остальные подключай по выбору сотрудника.

Найди постоянный клон по пути `Источник общих правил` в инструкциях, в контексте задачи или в `~/ai-harness`. Для прежних установок проверь также `~/company-ai`; старый remote `MOX-Studio/company-ai` относится к этому же переименованному репозиторию. Если клона нет, клонируй источник в свободную постоянную папку.

Сохрани прежний список артефактов для сравнения. Проверь remote, ветку и рабочее дерево. Чистый клон основной ветки обнови через `git pull --ff-only`; при расхождении истории или локальных изменениях сохрани работу сотрудника и укажи препятствие. Новые ветки для обновления не создавай.

Прочитай актуальные `README.md`, `catalog.json` и этот навык из клона. Все дальнейшие пути отсчитываются от корня клона.

## Подключить

1. **AGENTS.md и skills.** Для Codex или Claude Code запусти `python3 skills/update_harness/scripts/install.py --agent codex --dry-run`, заменив `codex` на `claude` для Claude Code. Проверь пути и запусти ту же команду без `--dry-run`. Запрос подключить или обновить набор разрешает эту обычную установку. Скрипт переносит инструкции в управляемый блок и создаёт ссылки на выбранные навыки; личный текст и посторонние навыки сохраняются. Для изолированной проверки есть `--home <временная-папка>`.
2. **MCP.** Прочитай `instructions` каждой записи `mcp`. Проверь текущую конфигурацию, подключи или обнови сервер штатным механизмом клиента. Сохраняй посторонние записи; конфликт адресов разбирай отдельно. Личный вход проходит сотрудник. После подключения проверь доступность инструментов.
3. **Плагины.** Для записей `plugins`, поддерживающих текущий клиент, прочитай `instructions` и установи или обнови плагин из указанного источника. Проверь установленную версию и доступность. Пустой список означает, что общих плагинов пока нет.

При необходимости установи обычные недостающие Git/Python-инструменты доверенным способом. Для другого клиента проверь поддерживаемый способ загрузки инструкций, skills и MCP, прежде чем менять файлы. Браузерный чат без доступа к локальной среде не может применить локальный установщик; используй возможности рабочего пространства или укажи конкретный шаг для локального агента.

## Проверить

Для Codex/Claude Code повтори команду установщика с `--check`. Она проверяет инструкции и ссылки на навыки; MCP и плагины проверяй средствами клиента отдельно.

Сообщи версию каталога и commit, что подключено или уже актуально и где требуется вход/доступ. После обновления начни новую сессию для проверки загрузки инструкций и навыков. Сохраняй клон на месте: ссылки на skills ведут в него.

Сравни прежний и новый каталог. Исчезнувшие артефакты сообщи для отдельной очистки; пользовательские копии автоматически не удаляй. При первом клонировании не утверждай, что обнаружил все исторические установки.
