# /update_harness

Источник: https://github.com/MOX-Studio/ai-harness

1. Определи текущий клиент. Найди клон по пути `Источник общих правил`, из контекста задачи или в `~/ai-harness`. Если его нет, клонируй источник в постоянную папку.
2. Запомни прежний каталог. Проверь remote, ветку и рабочее дерево. Чистый клон основной ветки обнови через `git pull --ff-only`. При конфликте сохрани изменения и сообщи причину; ветки не создавай.
3. Прочитай обновлённые `catalog.json`, `AGENTS.md` и этот навык. Все пути ниже — от корня клона.
4. Подключи инструкции и skills командой ниже. Проверь пути, повтори без `--dry-run`, затем с `--check`. Для Claude Code замени `codex` на `claude`. Запрос обновить набор разрешает эту установку.

```sh
python3 skills/update_harness/scripts/install.py --agent codex --dry-run
```

5. Для MCP и плагинов прочитай `instructions` из каталога. Подключи или обнови совместимые записи средствами клиента. Сохраняй остальные настройки; конфликт имён/адресов разбирай отдельно. Личный вход проходит пользователь. Проверь доступность инструментов и версии плагинов.
6. Сообщи версию каталога, commit, результат и недостающие доступы. Исчезнувшие из каталога артефакты перечисли для отдельной очистки; автоматически не удаляй.

Сохраняй личные дополнения. Клон оставь на месте: навыки подключены ссылками. После установки или обновления начни новую сессию для проверки загрузки.

Установщик: macOS/Linux, Git, Python 3.9+. Для другого клиента сначала проверь способ подключения. Без доступа к локальным файлам используй возможности рабочего пространства или укажи необходимый локальный шаг.
