# /update_harness

Источник: https://github.com/MOX-Studio/ai-harness

Изменяй профиль только по запросу установки или обновления harness.

1. Найди клон по пути `Источник общих правил`, из контекста или в `~/ai-harness`. Если его нет, клонируй источник в постоянную папку.
2. Запомни прежний каталог. Проверь remote, ветку и рабочее дерево. Чистый клон основной ветки обнови через `git pull --ff-only`. При конфликте сохрани изменения и сообщи причину; ветки не создавай.
3. Прочитай обновлённые `catalog.json`, `AGENTS.md` и этот навык. Пути ниже — от корня клона. Устанавливай только записи каталога.
4. Выполни команду ниже. Проверь пути, повтори без `--dry-run`, затем с `--check`.

```sh
python3 skills/update_harness/scripts/install.py --dry-run
```

5. Для MCP и плагинов прочитай `instructions`. Установи или обнови записи средствами Codex; пустые списки пропусти. Сохраняй прочие настройки. Конфликты имён/адресов не перезаписывай. Пользователь завершает необходимую авторизацию. Проверь инструменты MCP и версии плагинов отдельно от `--check`.
6. Сообщи версию каталога, commit, результат и недостающие доступы. Исчезнувшие записи перечисли для отдельной очистки; автоматически не удаляй.

Сохраняй личные дополнения и клон: навыки подключены ссылками. Проверь загрузку в новой сессии Codex, если среда позволяет; иначе укажи необходимость перезапуска.

Установщик требует macOS/Linux, Git и Python 3.9+. Без доступа к пользовательским файлам укажи конкретное ограничение; не объявляй установку выполненной.
