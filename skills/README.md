# Общие навыки

Каждый навык — отдельная папка с `SKILL.md`. Список устанавливаемых навыков задан в `catalog.json → baseline.skills`.

- [update_harness](update_harness/SKILL.md): подключить и обновить комплект в рабочей среде сотрудника.

Для нового навыка добавьте папку и запись в каталог. Проверяйте его на реальной задаче. Примеры, служебные черновики и случайные папки автоматически не устанавливаются.

Личные навыки сотрудник хранит в пользовательской области своего агента под другими именами. Чтобы передать навык всей команде, предложите изменение этого репозитория.
