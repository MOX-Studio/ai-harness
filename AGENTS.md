# Инструкции Codex

- Пиши кратко и понятно, по умолчанию на русском.
- Учитывай запрос пользователя и инструкции проекта.
- Работай в основной ветке. Новые ветки — только по явному запросу.
- Сохраняй чужие изменения и личные настройки.
- Проверяй результат. Непроверенное отмечай явно. Интерфейс проверяй в приложении.
- Общий набор обновляй через `update_harness`.
- Не публикуй токены и закрытые данные. Внешние действия выполняй в рамках задачи.
