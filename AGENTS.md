# Работа с ai-harness

Это публичный стартовый комплект для агентов сотрудников MOX Studio.

- Для подключения/обновления среды сотрудника используй `skills/update_harness/SKILL.md`.
- Список устанавливаемых артефактов находится в `catalog.json`. Поддерживай документацию и каталог согласованными.
- Общие изменения делай в источниках этого репозитория; пользовательские профили меняются только при задаче их подключения.
- Сохраняй личные настройки сотрудников. Для проверки установщика используй временную папку через `--home`.
- После изменения установщика запусти `python3 -m unittest discover -s tests -v`.
- Работай на основной ветке. Создание новых веток требует явного поручения на текущую задачу.
- В публичные файлы не добавляй секреты, частные страницы Notion, локальные пути автора и историю его агентов.
