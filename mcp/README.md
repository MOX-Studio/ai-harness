# Подключения

Активный список находится в `catalog.json → mcp`. Агент обрабатывает его через навык `company-sync`; локальный установщик правил не изменяет MCP-конфигурацию.

- [Notion / MOX Space](notion.md)

Для нового подключения укажите назначение, официальный источник, адрес или локальный пакет, поддерживаемые клиенты, способ личной авторизации, порядок обновления и безопасную проверку чтением. Если уже есть работающее подключение к тому же источнику, используйте его.
