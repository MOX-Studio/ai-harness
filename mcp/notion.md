# Notion / MOX Space

Назначение: дать агенту доступ к базе знаний сотрудника. Для знакомства с проектом достаточно чтения [MOX Space](https://app.notion.com/p/mox-studio/MOX-Space-dd7285aa22f7432fbe031f958b2b5da7).

## Сначала проверить существующее подключение

Если доступны `notion-axi`, Notion-плагин или MCP, попробуйте прочитать указанную страницу. Работающее подключение можно сохранить.

Для `notion-axi` используйте личный `NOTION_API_TOKEN` из окружения или принятого в компании локального хранилища. Токен не выводится в ответ и не попадает в файлы этого репозитория. Страница должна быть доступна выбранной интеграции. Команда проверки:

```sh
notion-axi page view dd7285aa22f7432fbe031f958b2b5da7
```

Ответ `object_not_found` может означать отсутствие доступа у интеграции; он не доказывает отсутствие самой страницы. Попросите владельца страницы предоставить доступ сотруднику и его интеграции. Не создавайте замену страницы.

## Подключить официальный MCP, если рабочего подключения нет

Официальный endpoint: `https://mcp.notion.com/mcp`. Авторизация — личный OAuth. [Документация Notion](https://developers.notion.com/guides/mcp/get-started-with-mcp).

Перед добавлением проверьте существующий сервер `notion`: если он уже настроен, сравните адрес. При другом адресе не заменяйте его автоматически.

### Codex

```sh
codex mcp get notion
codex mcp add notion --url https://mcp.notion.com/mcp
codex mcp login notion
```

Команду `add` выполняйте только если сервер отсутствует. Сотрудник завершает вход в Notion.

### Claude Code

```sh
claude mcp get notion
claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp
```

Команду `add` выполняйте только если сервер отсутствует. Затем сотрудник открывает `/mcp` в Claude Code и завершает вход.

## Подтверждение

После входа обновите подключения или начните новую сессию. Выполните чтение конкретной страницы MOX Space и сообщите, получилось ли получить её заголовок/содержимое. Настройка endpoint и успешный OAuth сами по себе не подтверждают доступ к этой странице.

Закрытое содержимое Notion остаётся в Notion. Общий репозиторий хранит способ подключения и ссылку.
