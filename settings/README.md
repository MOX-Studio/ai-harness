# Общие настройки

Общие текстовые инструкции уже находятся в `rules/common.md`. Дополнительные настройки модели, интерфейса и разрешений пока не выбраны: `catalog.json → settings` пуст.

Для пресета добавьте инструкцию и запись с полями `id`, `instructions`, `clients`, `projects`, `version`. Укажите точные параметры, область действия и способ проверки. Агент меняет только перечисленные параметры, сохраняя остальные настройки и локальную резервную копию исходного файла.

В общий комплект не входят личные токены, аккаунты, абсолютные пути автора и история диалогов. Пресеты следует проверять на поддерживаемых версиях приложения. Обязательные настройки рабочего пространства применяются административными средствами соответствующего продукта.
