# Как обновлять общий комплект

1. Добавьте или измените артефакт в подходящей папке. Для подключения запишите назначение, источник, клиентов, авторизацию и проверку результата.
2. Обновите `catalog.json`: только перечисленные там артефакты входят в комплект. Для навыков используйте папку `skills/<имя>` с `SKILL.md` и добавьте её в `baseline.skills`.
3. Поднимите `version` каталога при изменении устанавливаемого содержимого или способа подключения.
4. Проверьте установку на временном профиле и убедитесь, что личные файлы сохраняются. Для скрипта запустите `python3 -m unittest discover -s tests -v`.
5. Перед публикацией проверьте diff: репозиторий публичный. Включайте только материал, предназначенный для открытого распространения.
6. Передайте изменение на проверку коллегой через принятый командой процесс. Создание новой ветки определяется явным поручением сотрудника; агент не создаёт её автоматически.

Для проверки без изменения рабочего профиля используйте `--home` с отдельной временной папкой. После `--dry-run` убедитесь в путях, затем примените и выполните `--check`.

Публикация новой версии не изменяет компьютеры сотрудников мгновенно. Сотрудник запускает `update_harness`; ссылки на навыки используют содержимое его локального клона, а общий блок инструкций обновляется установщиком.

При удалении или переименовании артефакта опишите переход. Автоматического удаления пользовательских копий нет.
