# Проекты

Профиль проекта связывает общий комплект с кодом, документацией и рабочими сервисами.

- [MOX-ADV](mox-adv/README.md)

Для нового проекта создайте папку с `README.md` и запись в `catalog.json → projects`. Укажите репозиторий, базу знаний, порядок чтения, необходимые подключения и способ проверки доступа. Здесь достаточно ссылок и открытых вводных материалов; актуальные технические детали остаются в исходном проекте.
