# MOX-ADV

Проект автоматизации рекламной работы с Яндекс Директом и Метрикой. Текущий контекст уточняется по исходным документам и задаче сотрудника.

## Источники

| Источник | Для чего нужен |
| --- | --- |
| [MOX-Studio/MOX-ADV](https://github.com/MOX-Studio/MOX-ADV) | Код, инструкции и документация проекта |
| [AGENTS.md](https://github.com/MOX-Studio/MOX-ADV/blob/main/AGENTS.md) | Рабочие инструкции для агента в проекте |
| [CONTEXT.md](https://github.com/MOX-Studio/MOX-ADV/blob/main/CONTEXT.md) | Назначение проекта и его контекст |

| [Dashboard](https://github.com/MOX-Studio/MOX-ADV/blob/main/dashboard/README.md) | Документация приложения |
| [MOX Space](https://app.notion.com/p/mox-studio/MOX-Space-dd7285aa22f7432fbe031f958b2b5da7) | Командная база знаний; требуется доступ сотрудника |

## Порядок знакомства

1. Открой текущую основную ветку проекта. Начни с `AGENTS.md`, `CONTEXT.md`, `docs/adr/0001-agent-owns-safe-work.md` и `dashboard/README.md`; для конкретной папки прочитай применимые локальные инструкции.
2. Проверь доступ к MOX Space через имеющееся подключение Notion. Найди вводную документацию по проекту и текущей задаче сотрудника.
3. Сопоставь инструкции с фактической версией кода. При расхождении документации, текущего кода и указаний сотрудника сообщи о нём, сохрани происхождение каждого утверждения.
4. Перед изменениями проекта проверь рабочее дерево. Для подключения комплекта не нужно создавать новые ветки, worktree или менять remote проекта.

Для работы с Dashboard открой его собственный README и `package.json`: команды запуска и требования к Node берутся из той версии проекта, с которой работает сотрудник. Этот профиль не закрепляет архитектуру или команды из старого снимка.

## Подключения

- GitHub: доступ к репозиторию; для предложений изменений нужны соответствующие права.
- Notion: личное подключение и права на MOX Space. Инструкция: [Notion](../../mcp/notion.md).

При наличии `gh-axi` и `notion-axi` используй их. Доступный через интеграцию документ и документ, который сотрудник видит в браузере, могут различаться по правам.

## Проверка готовности

- Агент прочитал актуальные инструкции репозитория и назвал проверенную ветку/commit.
- Загружены общие правила MOX и навык `update_harness`.
- Агент смог прочитать MOX Space либо указал отсутствие доступа как незавершённый шаг.
- Сотрудник понимает, где находится код, база знаний, общий комплект и его личные дополнения.
